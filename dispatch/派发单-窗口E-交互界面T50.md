> **时间盒**：明天（10/12）10:00–12:00，**硬止损 2 小时**——超时立即降级或放弃，绝不阻塞主线（C 全量测试 / 合规 / 终审 / 提交）。
> **优先级**：低于一切已排定任务。若任何主线与本任务冲突，本任务让路。

---

## 任务目标

给系统加一个**可交互的本地界面**：用户点按钮就能"选数据集 → 跑计算 → 看结果图"，替代纯命令行体验。

## 技术方案（首选，可自主优化）

**Streamlit**（本机实测可用命令）：

```bash
pip install -i https://pypi.org/simple streamlit
```

理由：Python 原生、复用现有模块最省力、自带组件（下拉框/按钮/图片展示）、几十行代码即可。

**降级预案（按顺序）**：
1. 若 Streamlit 安装失败（网络/依赖冲突）→ 换 Gradio（同思路）
2. 若两者都不行 → 降级为**纯静态切换页**：把 t25-final 与 t25-baseline 两套报告汇总为一个带"优化/基线"切换按钮的 HTML（零依赖）
3. 若时间超了 → 直接放弃，回报"未完成"，主规划接受

## 功能范围

**MVP（必须）**：
1. 页面顶部：下拉选择数据集（seed42 / seed7）
2. "运行智能配载"按钮 → 调用现有管线（`run.py` 的求解逻辑或直接调用 solver 模块）
3. 结果展示：
   - 核心指标（车辆数 / 里程 / 运输费 / 装下率）卡片
   - 路线图（route_map.png）
   - 各车厢 3D 装载图（packing_V*.png）

**加分项（有余力才做）**：
4. "对比基线"开关（勾选后同时跑 baseline 并显示对比表）
5. 显示分步骤装卸指引文本

## 硬约束

1. **零侵入**：不得修改任何现有模块代码（`solver/` `eval/` `agent/` `report/` `run.py` 一行都不许动），只允许 import 复用与新文件
2. **产物隔离**：运行产物写入临时目录（如 `outputs/app-tmp/`），**绝不覆盖** `outputs/t25-final/` 与 `outputs/t25-baseline/`
3. **新文件**：`app.py`（根目录）、可选 `requirements-app.txt`（若不想把 streamlit 加进主 requirements.txt）
4. **依赖**：若把 streamlit 写入主 `requirements.txt`，必须到主规划报备；默认建议单独放 `requirements-app.txt` 并在 README 注一句

## 交付物

| 文件 | 说明 | 验收 |
|------|------|------|
| `app.py` | 交互界面主程序 | `streamlit run app.py` 一条命令启动，浏览器自动打开 |
| 运行说明 | README 增补一小节（由主规划统一改）或 app 内说明 | 说明包含：安装命令 + 启动命令 |

**验收标准**：
- 一条命令启动 → 浏览器打开 → 选数据集 → 点按钮 → 2 分钟内出结果（指标 + 路线图 + 3D 图）
- 点两次（seed42/seed7）都不报错
- 不影响已入库产物（跑完后 `git status` 干净，除新文件外）
