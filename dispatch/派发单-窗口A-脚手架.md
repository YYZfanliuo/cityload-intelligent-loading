### T01 · GitHub 私有仓库 + 目录结构【截止 10/11 13:00】

**输入**：无
**交付物**：
1. GitHub 私有仓库（仓库名建议 `cityload-intelligent-loading`）
2. 本地目录结构（已由主规划窗口预建，见下表，确认齐备即可）

4. `.gitignore`（忽略 `output/figures/*.png`、`__pycache__/`、`.venv/`、`*.pyc`）

```

```

**验收标准**：

- `git branch -a` 显示 `main` 和 `dev`
- 目录结构完整

## 技术方案要点（供你理解上下文）

- 语言：Python 3.10+
- 求解：OR-Tools（CVRPTW）
- 装箱：py3dbp 或自研启发式
- 可视化：matplotlib
- 无前端框架，最终产物是静态 HTML 报告

## 协作规则

1. 所有代码提交到 `dev` 分支并开 PR，主规划窗口验收后合并 `main`
2. 遇到接口问题以 `docs/interfaces.md` 为准
3. 完成后回报格式：`【T01 完成】交付物路径 + 自测结果`
